Jun 22, '24 | Google IO Extended, GDG Cloud Kuala Lumpur, Malaysia

Architecting AI Agents: Supercharge your workflows with Vertex AI

This talk dives into the fast-evolving world of AI agents and their powerful capabilities. Starting with a comprehensive introduction, it explores the core concepts involved in designing an AI agent. It also briefly covers basics of RAGs and LLMs. The talk then goes over the different agent architectures leveraging Vertex AI such as AI agent builder, native function calling and Langchain with Vertex AI, and evaluates the pros and cons of each. Finally, the talk wraps up with some real-world examples and a live demo of the AI agent builder.    [Slides]

Apr 18, '24 | Women TechMakers & GDG Cloud, Singapore

Rigging with RAG: How to build a retrieval augmented chatbot with Vertex AI

This talk explores the process of designing an AI chatbot using Retrieval Augmented Generation. We cover the technical components of building a RAG-powered chatbot using Vertex AI through a detailed code walkthrough. Following the walkthrough, there is a demo of the chatbot built using Vector Search and GCS. The nuances of building different kinds of knowledge bases and an evaluation framework for the decision to invest in chatbot development is also covered.    [Slides]
