description: "We use a codelab to learn about building multi-agent systems with Google ADK. Through creating a set of specialized agents that collaborate to solve a complex task, participants will learn about concepts such as subagents, remote agents and orchestration agents. This is a hands-on workshop where we build a Course Creation System composed of a Researcher Agent (gathers information via Google Search), a Judge Agent (evaluates research quality), a Content Builder Agent (turns research into a structured course), and an Orchestrator Agent that coordinates the workflow between them."
